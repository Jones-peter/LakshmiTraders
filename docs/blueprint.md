# **App Name**: Lakshmi Traders

## Core Features:

- Login Authentication: Secure user authentication using Firebase Auth for admin access.
- Batch Management: Create new batches of vegetables, recording details like type (e.g., onion), quantity (kg), purchase price, and associated expenses. Batches will get a unique automatically generated ID.
- Customer Management: Add and manage customer information, including name, contact details, and payment history.
- Sales Tracking: Record sales transactions for each batch, track payment status (paid/unpaid), and calculate revenue per batch.
- Revenue and Outstanding Payments Reporting: Display outstanding customer payments and generate revenue reports for selected months and years.

## Style Guidelines:

- Primary color: Green (#4CAF50) to represent freshness and growth.
- Secondary color: Light gray (#F5F5F5) for backgrounds to ensure readability.
- Accent: Orange (#FF9800) for interactive elements and call-to-action buttons.
- Clear and readable sans-serif font for all text elements.
- Simple, outline-style icons for navigation and actions.
- Clean, grid-based layout with clear sections for batch management, customer management, and reporting.
